# TESLA ROADSTER 2 — THE FUTURE OF SPEED

A responsive, independent concept website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — semantic page structure, content, enquiry form and metadata
- `style.css` — responsive visual design, animation, cards, gallery and mobile layout
- `script.js` — navigation, scroll reveals, gallery lightbox/filter, concept viewer controls and WhatsApp form
- `reference-design.png` — supplied visual reference (for design comparison only)

## Run in VS Code
1. Extract the ZIP file.
2. Open the `tesla_roadster_concept` folder in Visual Studio Code.
3. Install the **Live Server** extension if you do not already have it.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Keep an internet connection available for the externally hosted automotive images and Google Fonts.

You can also double-click `index.html` to open it in a browser. Live Server is recommended for testing.

## Publish online
You can publish the folder using GitHub Pages, Netlify, or another static-hosting service:
- Upload all three site files (`index.html`, `style.css`, `script.js`) and keep their filenames/paths unchanged.
- For GitHub Pages, create a repository, upload the files to its root, then enable Pages in repository settings.
- For Netlify, deploy the extracted folder as a static site.
- Test the published site on Android, iPhone-sized viewport, and desktop.

## Image and brand notes
The imagery is illustrative automotive photography loaded from Unsplash image URLs. It is not represented as official Tesla Roadster 2 product imagery. An internet connection is needed to load these remote images. Replace image URLs with your own licensed images if preferred.

The viewer is a 2D image-based fallback with CSS colour treatments; it is not a real 3D model or Three.js configurator.
